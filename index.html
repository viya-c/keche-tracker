⚠️ 看不到你之前的数据？点这里看恢复方法 展开 ▾

本应用的数据保存在你打开这个 HTML 文件的浏览器里，且与文件打开位置（完整路径）绑定。换位置 / 改文件名 / 换浏览器 / 无痕窗口，浏览器都会当成"另一个应用"，读不到旧数据。

📱 手机用户特别注意：

  • 用微信 / QQ 直接预览打开，每次都是临时路径，数据几乎一定丢失 → 请用手机「文件管理」把 HTML 存进一个固定文件夹，从那里打开。
  • iPhone 的 Safari 对本地 HTML 的存储经常不保留（关掉文件数据就可能清空），这是系统限制，不是本应用的问题。

恢复方法（按顺序试）：

  1. 找到你当初记录数据时打开文件的那个手机文件夹，把当前这个 课时追踪器-2026.html 放进去，从那里打开 → 旧数据可能自动出现。
  2. 数据一出现，立刻点工具栏 📦 自包含备份（数据内嵌进文件，换哪都丢不了）。
  3. 若你之前导出过 💾 备份 JSON 或 📦 自包含备份 .html，用 📂 导入 选它恢复。
  4. 若既无备份、又找不到原打开位置（或 iPhone 已清存储），数据确实无法找回，只能重录。
⚠️ 有改动尚未备份！点工具栏 📦 自包含备份 把数据存进文件，换手机 / 换路径都不会丢。
